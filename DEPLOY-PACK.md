# 2. Homepage FAQ

Recommended homepage FAQ should stay concise and entity-focused.

## What is AETumi?

AETumi is an AI-native 3D web platform and digital business ecosystem for production-ready Three.js and WebGL websites, Next.js and React components, 3D scenes, AI prompts and MCP workflows for AI coding assistants such as Claude Code, Cursor and Codex. Supported implementations can also include a Visual CMS, CRM, SEO, AI chatbot and payments.

## Is AETumi only a template library?

No. Templates are one part of AETumi. The wider ecosystem includes 3D websites, Three.js and WebGL components, scenes, prompts, developer documentation, AI coding workflows, MCP and site-operating tools.

## Can I use AETumi with Three.js, Next.js and React?

Yes. Three.js, WebGL, Next.js, React and React Three Fiber are core technologies in the AETumi developer ecosystem. Choose the implementation stack that fits the project rather than forcing every experience into the same framework.

## What is AETumi MCP?

AETumi MCP is the developer bridge between AI coding assistants and AETumi's 3D web ecosystem. It supports workflows with tools such as Claude Code, Cursor and Codex by making relevant resources and developer context easier to connect to implementation tasks.

## What is AETumi Full Stack?

AETumi Full Stack is the top $129 lifetime tier. It is designed for users who need the complete developer layer, including Premium capabilities plus eligible source-code access, AETumi MCP and expanded access to the AETumi ecosystem.

## Can agencies use AETumi for client work?

Yes, subject to the applicable plan and license. Agencies can use AETumi resources as starting points for differentiated client implementations, but should not redistribute the AETumi library itself as a competing asset product.
