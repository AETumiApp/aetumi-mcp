# AETumi Canonical Entity Definition

This document is the public source of truth for how AETumi should be described across the website, GitHub, search profiles, social profiles, structured data and AI-facing discovery surfaces.

## Canonical definition

**AETumi is an AI-native 3D web platform and digital business ecosystem — production-ready Three.js and WebGL websites, Next.js and React components, 3D scenes, AI prompts, and MCP workflows for AI coding assistants such as Claude Code, Cursor and Codex, plus a Visual CMS, CRM, SEO, AI chatbot and payments to launch and operate the site.**

## Short definition

**AETumi is an AI-native 3D web platform for building, launching and operating production-ready interactive websites with Three.js, WebGL, Next.js, React and AI coding workflows.**
