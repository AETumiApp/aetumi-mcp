# Contributing to AETumi's Public Developer Repositories

AETumi's public repositories are intended to be useful technical references for 3D web developers, designers and agencies. Contributions should improve clarity, correctness, implementation quality or production readiness.

## Good contributions

Examples include:

- correcting Three.js, WebGL, React or Next.js implementation details
- improving loading, cleanup, accessibility or responsive behavior
- adding a small reproducible example
- documenting a real edge case
- improving explanation without turning documentation into keyword repetition
- fixing broken links or outdated references

## Before opening a change

1. Keep the repository's primary purpose intact.
2. Prefer small, reviewable changes.
3. Explain why the change is useful in production.
4. Avoid adding dependencies when plain platform or library APIs are sufficient.
5. Do not include proprietary third-party source code or assets without permission.

## Code expectations

Where code is added, prefer:

- readable structure over compressed cleverness
- explicit cleanup for WebGL resources
- responsive behavior
- reduced-motion and fallback handling when relevant
- semantic HTML outside the 3D canvas for important content
- comments only where they clarify non-obvious behavior

## Documentation expectations

Documentation should be original, specific to the repository and technically useful. Repeating the same paragraph across many repositories makes the network less useful to both humans and search systems.

## Security

Do not commit secrets, API keys, credentials, private customer data or proprietary assets.
