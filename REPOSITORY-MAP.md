# AETumi Repository Map

AETumi's public GitHub repositories are intentionally split by implementation intent. Each repository has one primary job so the network remains useful to developers rather than becoming a pile of near-duplicate keyword pages.

## Repository descriptions

| Repository | Primary description | Canonical AETumi page |
| --- | --- | --- |

| `threejs-product-viewer` | Production patterns for Three.js product viewers, configurators, hotspots, variants and interactive ecommerce experiences. | https://aetumi.app/threejs/ |
