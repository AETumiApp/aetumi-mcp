# AETumi Ecosystem

This document is the canonical public map of the AETumi developer ecosystem.

## Canonical entity statement

**AETumi is an AI-native 3D web platform for production-ready Three.js and WebGL websites, Next.js and React components, 3D scenes, AI prompts, and MCP workflows for AI coding assistants.**

## Technology relationships

AETumi connects these technical domains:

**3D Web → Three.js → WebGL → Next.js → React → React Three Fiber → MCP → Claude Code / Cursor / Codex**

The relationships are intentional:

- **Three.js** provides the primary browser 3D layer.
- **WebGL** powers shader-driven graphics and GPU rendering beneath many interactive experiences.
- **React** and **Next.js** provide application structure, routing and production delivery.
- **React Three Fiber** offers a React renderer for Three.js where component-driven scene architecture is useful.
- **MCP** connects AI coding assistants to structured tools and project context.
- **Claude Code, Cursor and Codex** are examples of AI coding workflows that can accelerate implementation while developers retain architectural control.

## Quality principles

AETumi's developer content should consistently favor:

1. Useful implementation detail over keyword repetition.
2. Production constraints over visual demos that only work on one machine.
3. Semantic HTML and crawlable content alongside client-side 3D rendering.
4. Mobile, accessibility and reduced-motion fallbacks.
5. Clear relationships between website content, GitHub examples and developer documentation.
6. Original examples and explanations rather than duplicated repository text.
