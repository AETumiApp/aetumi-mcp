# AETumi MCP

AETumi MCP connects AI coding assistants such as Claude Code, Cursor and Codex to AETumi's 3D web ecosystem for Three.js, WebGL, Next.js and React.

## What is AETumi?

AETumi is an AI-native 3D web platform for production-ready Three.js and WebGL websites, Next.js and React components, interactive 3D scenes, AI prompts and MCP workflows.

## What this repository is for

This public repository is the technical home for AETumi MCP integration notes, examples and developer workflows. It is intended to help developers connect AI coding assistants to AETumi resources and build interactive 3D web experiences faster.

## Core technologies

- Three.js
- WebGL
- Next.js
- React
- MCP
- Claude Code
- Cursor
- Codex

## Typical workflow

1. Ask your AI coding assistant for a 3D web requirement.
2. Search or reference the relevant AETumi asset, prompt, component or scene.
3. Bring the result into a Three.js, WebGL, Next.js or React project.
4. Customize the visual system, motion, interaction and product experience.
5. Test performance, accessibility and responsiveness.
6. Ship.
