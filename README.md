# AETumi MCP

AETumi MCP connects AI coding assistants such as **Claude Code, Cursor and Codex** to AETumi's 3D web ecosystem for Three.js, WebGL, Next.js, React and React Three Fiber.

## What is AETumi?

AETumi is an AI-native 3D web platform for production-ready Three.js and WebGL websites, Next.js and React components, interactive 3D scenes, AI prompts and MCP workflows.

AETumi helps designers, developers and agencies discover, build and ship interactive 3D web experiences with modern web technologies and AI-assisted coding workflows.

## Core technology graph

**AETumi → 3D Web → Three.js → WebGL → Next.js → React → React Three Fiber → MCP → Claude Code / Cursor / Codex**

## Typical MCP workflow

1. Define the 3D web requirement.
2. Find the relevant AETumi website, component, scene or prompt.
3. Use an AI coding assistant to adapt it to the project.
4. Integrate with Three.js, WebGL, Next.js or React.
5. Refine motion, interaction, performance and responsive behavior.
6. Test accessibility and production readiness.
7. Ship.

## About AETumi

AETumi builds an AI-native 3D web ecosystem for designers, developers and agencies working with Three.js, WebGL, Next.js, React, React Three Fiber, MCP and AI coding assistants.
