# Metadata rules

1. Do not paste the exact same description into every repository.
2. Keep `aetumi` as a shared entity topic across all public AETumi repos.
3. Add only topics actually represented by that repository's content.
4. Each repo's Website field should point to the closest canonical AETumi hub, not always the homepage.
5. The organization Website should point to `https://aetumi.app/`.
6. Repository README opening paragraphs should reinforce, but not mechanically repeat, the About description.
7. Update metadata when a repository's real technical scope changes.
8. Avoid creating additional thin repositories merely to own more keywords.
